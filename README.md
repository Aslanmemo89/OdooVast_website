# ماڵپەڕی OdooVast

ماڵپەڕی فەرمی **OdooVast** — هاوبەشی Odoo لە هەولێری عێراق.
دروستکراوە بە **Next.js 14** و **TypeScript** و **CSSی سادە** — هیچ داتابەیس،
هیچ باکئێند، هیچ پاکێجی زیادە نییە. هەموو لاپەڕەکان وەک HTMLی جێگیر
(static) دروست دەکرێن، بۆیە زۆر خێرایە و بۆ گووگڵ باشترینە.

**سێ زمان:** ئینگلیزی (`/en`)، عەرەبی (`/ar`)، کوردی سۆرانی (`/ckb`) —
عەرەبی و کوردی بە تەواوی ڕاست-بۆ-چەپن.

---

## چۆن لەسەر کۆمپیوتەرەکەت کاری پێ بکەیت

پێویستە **Node.js 18** یان نوێتر دامەزرابێت. پاشان لە فۆڵدەری پڕۆژەکەدا:

```bash
npm install     # یەک جار، بۆ داگرتنی پێداویستییەکان
npm run dev     # سێرڤەری گەشەپێدان — http://localhost:3000
npm run build   # دروستکردنی وەشانی کۆتایی (پێش بڵاوکردنەوە تاقی بکەرەوە)
```

## چۆن دەقێک بگۆڕیت

**هەموو نووسینەکانی ماڵپەڕەکە لە یەک فۆڵدەردایە:** `src/content/`

| فایل | ناوەڕۆک |
|---|---|
| `src/content/company.ts` | ژمارە تەلەفۆن، ئیمەیڵ، ناونیشان، کاتی کارکردن، سۆشیال میدیا، ژمارە ئامارەکان |
| `src/content/services.ts` | خزمەتگوزارییەکان (١٢ دانە) |
| `src/content/industries.ts` | کەرتەکان (٦ دانە) |
| `src/content/timeline.ts` | مێژووی کۆمپانیا |
| `src/content/pages.ts` | دەقی لاپەڕەکان: سەرەکی، دەربارە، کارەکانمان، پەیوەندی + تایتڵی SEO |
| `src/content/pricing.ts` | لاپەڕەی نرخەکان: نرخەکانی Odoo، جیاوازییەکان، پرسیارەکان و دەقی ژمێرەرەکە |

هەر دەقێک بەم شێوەیە نووسراوە — **هەر سێ زمانەکە پێویستە**:

```ts
title: {
  en: "Odoo Implementation",      // ئینگلیزی
  ar: "تطبيق Odoo",               // عەرەبی
  ckb: "جێبەجێکردنی Odoo",        // کوردی
},
```

ئەگەر یەکێک لە زمانەکان بسڕیتەوە، `npm run build` هەڵە دەدات — ئەمە
بە ئەنقەستە: ناهێڵێت وەرگێڕانێک لەبیر بکرێت.

## چۆن خزمەتگوزارییەکی نوێ زیاد بکەیت

1. `src/content/services.ts` بکەرەوە.
2. یەکێک لە خزمەتگوزارییە ئێستاکان کۆپی بکە (لە `{` تا `},`).
3. بیگۆڕە: `slug` (ناوی یەکتا بە ئینگلیزی)، `icon`، `title`، `summary`،
   `includes`، `suitedFor` — هەر سێ زمانەکە.
4. `core: true` واتە لە لاپەڕەی سەرەکیش دەردەکەوێت (تەنها ٦ دانە `core` بن).
5. ئایکۆنەکان لە `src/components/Icon.tsx` دان — ناوی یەکێکیان بەکاربهێنە
   یان نوێیەک زیاد بکە.

بۆ کەرتێکی نوێ هەمان شت لە `src/content/industries.ts` بکە.

## چۆن کڕیارێکی نوێ زیاد بکەیت

1. لۆگۆکە بخە ناو `public/clients/` (باشترە PNG بێت بە باکگراوندی ڕوون).
2. `src/content/clients.ts` بکەرەوە و یەکێک لە کڕیارەکان کۆپی بکە.
3. بیگۆڕە:
   - `name` — ناوی کۆمپانیا بە پیتی لاتینی (لە هەر سێ زمانەکەدا وەک خۆی دەمێنێتەوە).
   - `sector` و `about` — بوار و کارەکەی، هەر سێ زمانەکە.
   - `branches` — شار و وڵاتەکان، وەک `{ place: "erbil", count: 2 }`. ئەگەر
     ژمارەی لقەکان نازانیت `count` مەنووسە. شار و وڵاتەکان: `erbil`،
     `baghdad`، `mosul`، `duhok`، `turkey`، `syria`، `china` — شوێنی نوێ لە
     سەرەوەی هەمان فایل لە `places` زیاد بکە (ئەگەر لە دەرەوەی عێراقە، لە
     `abroad`یش زیادی بکە).
   - `branchTotal` — کۆی لقەکان کاتێک تەنها ژمارەیەکی گشتی زانراوە بەبێ
     ژمارەی هەر شارێک؛ ئەگەر شارەکانیش نازانرێن `branches: []` بنووسە (وەک
     Aljawahir).
   - `factories` — ژمارەی کارگەکان، ئەگەر هەیانە.
   - `headOffice` — لقی سەرەکیی ئەو مارکەیەی کڕیارەکە دەیفرۆشێت، ئەگەر لە
     دەرەوەی عێراقە.
   - `darkArtwork: true` — تەنها ئەگەر لۆگۆکە باکگراوندی تاریکی خۆی هەبێت.
   - `logo`، `width`، `height` — ڕێڕەوی وێنەکە و قەبارەی ڕاستەقینەی بە پیکسڵ.
4. `npm run build` — ژمارەی لقەکان بە شێوەی دروستی هەر زمانێک دەنووسرێت
   (وەک «فرعان»، «٧ لق»، «4 factories»).

## چۆن نرخەکان نوێ بکەیتەوە

لاپەڕەی **نرخەکان** (`/pricing`) نرخەکانی **Odoo** پیشان دەدات، نەک نرخی
OdooVast. هەموو ژمارەکان لە یەک شوێندان: `src/content/pricing.ts` → `rates`.

1. [odoo.com/pricing](https://www.odoo.com/pricing) و
   [odoo.sh/pricing](https://www.odoo.sh/pricing) لە عێراقەوە بکەرەوە —
   Odoo بە پێی وڵات نرخ دادەنێت.
2. لە `rates` ژمارەکان بگۆڕە: `licence` (ستاندارد و تایبەت، ساڵانە و مانگانە،
   لەگەڵ نرخی ئاسایی دوای ١٢ مانگ)، `lightUser`، و `sh` (وۆرکەر، GB، سێرڤەری
   تایبەت، ژینگەی تاقیکردنەوە).
3. ڕێکەوتەکە لە `source.checked` و `source.checkedIso` نوێ بکەرەوە.
4. `npm run build` — کارتەکان، خشتەکان و ژمێرەرەکە هەموویان لەو ژمارانەوە
   دەخوێننەوە.

نرخی کاری OdooVast خۆی (جێبەجێکردن، ڕاهێنان، گەشەپێدان) لەم لاپەڕەیەدا
نییە — دوای ڕاوێژکاری دیاری دەکرێت.

## جووڵە و 3D

- **دیمەنی کردنەوە** (`src/components/Intro.tsx`) — تەنها لە لاپەڕەی سەرەکی،
  تەنها کاتێک کەسێک لە دەرەوەی ماڵپەڕەکەوە دێت (نەک لە reload یان لە
  لاپەڕەیەکی ترەوە)، نزیکەی ٢ چرکە، و بە هەر کلیکێک تێدەپەڕێت. هیچ شتێک لە
  وێبگەڕدا پاشەکەوت ناکات. بۆ لابردنی، `<Intro />` لە
  `src/app/[locale]/page.tsx` بسڕەوە.
- **گۆی 3D لە سەرەوەی لاپەڕەی سەرەکی** (`src/components/HeroScene.tsx`) —
  ناوی ئەو ئەپانەی بە دەوریدا دەسووڕێنەوە لە `src/content/pages.ts` →
  `home.orbit` دان.
- **جووڵەی ماوس** (`src/lib/pointer.ts`) — تەنها لەسەر ئامێری خاوەن ماوس بار
  دەبێت؛ مۆبایل دایناگرێت. هەر توخمێک `data-tilt="7"`ی هەبێت بەرەو ماوس لار
  دەبێتەوە (ژمارەکە زۆرترین گۆشەیە بە پلە).
- **ڕێکخستنەکان** لە سەرەوەی `src/app/globals.css`: `--perspective`،
  `--lift-1` تا `--lift-3`، `--shadow-3d`.
- ئەو کەسانەی لە ڕێکخستنی ئامێرەکەیاندا «کەمکردنەوەی جووڵە» (Reduce motion)یان
  هەڵبژاردووە، ماڵپەڕێکی جێگیر و بێ جووڵە دەبینن.

## چۆن بڵاوی بکەیتەوە (Deploy)

باشترین ڕێگا **Vercel**ـە (خۆڕاییە بۆ ئەم قەبارەیە):

1. بچۆ بۆ [vercel.com](https://vercel.com) و بە هەژماری GitHub بچۆ ژوورەوە.
2. **Add New → Project** و ئەم ڕیپۆیە هەڵبژێرە
   (`Aslanmemo89/OdooVast_website`).
3. هیچ ڕێکخستنێک مەگۆڕە — Vercel خۆی Next.js دەناسێتەوە. **Deploy** دابگرە.
4. لە **Settings → Domains** دۆمەینی `www.odoovast.com` زیاد بکە و
   ئەو DNSـە دابنێ کە Vercel پێت دەڵێت.

دوای ئەوە، هەر `git push` بۆ لقی `main` خۆکارانە ماڵپەڕەکە نوێ دەکاتەوە.
